A API da Real Oficial recebe um vídeo longo, encontra os melhores momentos, gera os
cortes, renderiza os arquivos e publica nas redes sociais. Tudo o que está nesta
documentação pode ser chamado da sua aplicação com um Bearer Token.

Qualquer conta pode usar a API, inclusive a gratuita. O que muda entre os planos são os
créditos e os limites de cada operação. Veja [Créditos e planos](/plans).

## Como a API funciona

Quase toda operação pesada é assíncrona: você cria o pedido, acompanha o status e usa o
resultado quando ele fica pronto.

```mermaid
sequenceDiagram
    participant App as Sua aplicação
    participant API as Real Oficial API

    App->>API: POST /createShorts (URL do vídeo)
    API-->>App: Projeto criado (pending)

    Note over API: Baixa, transcreve e encontra os cortes

    App->>API: GET /shorts/{projectId}
    API-->>App: Cortes com score

    App->>API: POST /shorts/{projectId}/{shortId}/render
    API-->>App: Render iniciado

    App->>API: GET /renders
    API-->>App: download_url do MP4
```

Para acompanhar, consulte o endpoint de status em intervalos ou configure um
[webhook](/api-reference/auth/profile#webhooks) para ser avisado quando um projeto ou um
render termina.

## O que dá para fazer

| Área | O que faz | Comece por |
|---|---|---|
| Cortes | Cria projetos a partir de um vídeo, lista e edita os cortes, renderiza os MP4 | [Criar Projeto com IA](/api-reference/projects/create) |
| IA | Auto Edit, dublagem, tradução de legendas, geração de imagem e vídeo, avatares e thumbnails | [Auto Edit](/api-reference/auto-edit) |
| Publicação | Conecta contas sociais, publica, agenda e organiza filas de postagem | [Publicações e Agendamento](/api-reference/social-posts) |
| Conteúdo | Brand kits, templates, biblioteca de arquivos e prompts, uploads de mídia | [Biblioteca](/api-reference/library) |
| Lives | Monitora lives da Twitch e da Kick e lista os cortes gerados a partir delas | [Iniciar Monitoramento](/api-reference/lives/monitor) |
