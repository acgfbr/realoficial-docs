## Fluxo básico de integração

```mermaid
sequenceDiagram
    participant App as Sua Aplicação
    participant API as Real Oficial API
    participant Worker as Workers

    App->>API: POST /login (credenciais)
    API-->>App: Token de autenticação

    App->>API: POST /createShorts (URL do vídeo)
    API-->>App: Projeto criado

    Worker->>Worker: Processa vídeo e gera cortes

    App->>API: GET /shorts/{projectId}
    API-->>App: Lista de cortes gerados

    App->>API: POST /shorts/{projectId}/{shortId}/render
    API-->>App: Renderização iniciada

    App->>API: GET /renders
    API-->>App: Status e URL do vídeo renderizado
```

## Rate Limits

A API possui limites de requisições para garantir estabilidade:

| Endpoint | Limite |
|----------|--------|
| Login | 60 requisições/minuto |
| Criar Projeto | 10 requisições/minuto |
| Renderizar | 50 cortes/hora (ilimitado no plano Business) |

### Limite de renderização

O limite é de **50 cortes por hora** para todos os planos, exceto o plano **Business**, que possui renderizações ilimitadas.

Pedidos de renderização não são rejeitados com base no tamanho atual da fila de processamento. As proteções contra render duplicado ou já em andamento continuam ativas.
