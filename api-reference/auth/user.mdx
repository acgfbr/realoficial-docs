## Endpoint

```
GET https://api.realoficial.com.br/api/v1/user
```

<Note>
Este endpoint requer autenticação via Bearer Token.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  Bearer Token do usuário
</ParamField>

## Resposta de Sucesso

<ResponseField name="user" type="object">
  Dados completos do usuário
  <Expandable title="Propriedades do usuário">
    <ResponseField name="id" type="string">
      ID único do usuário (ULID)
    </ResponseField>
    <ResponseField name="name" type="string">
      Nome do usuário
    </ResponseField>
    <ResponseField name="email" type="string">
      Email do usuário
    </ResponseField>
    <ResponseField name="token" type="string">
      Token de autenticação
    </ResponseField>
    <ResponseField name="balance" type="integer">
      Saldo atual de créditos
    </ResponseField>
    <ResponseField name="webhook_url" type="string">
      URL configurada para receber webhooks. `null` se não configurada.
      Editável via [Atualizar Perfil](/api-reference/auth/profile).
    </ResponseField>
    <ResponseField name="reprompts_daily_limit" type="integer">
      Quantidade de [reprompts](/api-reference/projects/reprompt) gratuitos por dia,
      conforme o plano.
    </ResponseField>
    <ResponseField name="reprompts_today" type="integer">
      Reprompts já realizados hoje.
    </ResponseField>
    <ResponseField name="reprompts_free_remaining" type="integer">
      Reprompts gratuitos restantes hoje. Chegando a `0`, os próximos passam a consumir
      créditos.
    </ResponseField>
    <ResponseField name="reprompts_reset_at" type="string">
      Data/hora em que a cota diária de reprompts é reiniciada (ISO 8601).
    </ResponseField>
    <ResponseField name="phone" type="string">
      Telefone do usuário (se cadastrado)
    </ResponseField>
    <ResponseField name="nickname" type="string">
      Apelido do usuário
    </ResponseField>
    <ResponseField name="is_phone_confirmed" type="boolean">
      Se o telefone foi confirmado
    </ResponseField>
    <ResponseField name="eligible_for_trial" type="boolean">
      Se está elegível para trial
    </ResponseField>
    <ResponseField name="eligible_for_roulette" type="boolean">
      Se pode girar a roleta de bônus
    </ResponseField>
    <ResponseField name="roulette_cooldown" type="integer">
      Tempo restante para próxima roleta (segundos)
    </ResponseField>
    <ResponseField name="checkin_cooldown" type="integer">
      Tempo restante para próximo check-in (segundos)
    </ResponseField>
    <ResponseField name="subscription" type="object">
      Dados da assinatura ativa
      <Expandable title="Propriedades da assinatura">
        <ResponseField name="id" type="string">
          ID da assinatura
        </ResponseField>
        <ResponseField name="status" type="string">
          Status: `active`, `cancelled`, `expired`, `pending`, `trialing`
        </ResponseField>
        <ResponseField name="plan" type="object">
          Dados do plano
        </ResponseField>
        <ResponseField name="ends_at" type="string">
          Data de expiração (ISO 8601)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.realoficial.com.br/api/v1/user" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://api.realoficial.com.br/api/v1/user', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer seu_token_aqui',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data.user);
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer seu_token_aqui',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://api.realoficial.com.br/api/v1/user',
    headers=headers
)

data = response.json()
print(data['user'])
```

```php PHP
$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'https://api.realoficial.com.br/api/v1/user',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer seu_token_aqui',
        'Content-Type: application/json'
    ]
]);

$response = curl_exec($ch);
$data = json_decode($response, true);
print_r($data['user']);
```

## Sistema de Créditos

<Info>
**1 crédito = 1 minuto de processamento de vídeo**

Os créditos são usados para:
- Processar novos vídeos (criar cortes)
- Gerar imagens com IA
</Info>

### Fontes de Créditos

| Fonte | Créditos |
|-------|----------|
| Bônus de registro | 60 |
| Check-in diário | 2-4 |
| Roleta  mensal| 150-1800 |
| Plano Lite (mensal) | 180 |
| Plano Criador (mensal) | 420 |
| Plano Viral (mensal) | 900 |
| Compra avulsa | Variável |
