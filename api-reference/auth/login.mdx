---
title: 'Login'
description: 'Autentique um usuário existente e obtenha o token de acesso'
---

## Endpoint

```
POST https://api.realoficial.com.br/api/v1/login
```

<Note>
Este endpoint não requer autenticação.
</Note>

## Body Parameters

<ParamField body="email" type="string" required>
  Email do usuário
</ParamField>

<ParamField body="password" type="string" required>
  Senha do usuário
</ParamField>

## Resposta de Sucesso

<ResponseField name="message" type="string">
  Mensagem de confirmação do login
</ResponseField>

<ResponseField name="user" type="object">
  Objeto com dados do usuário
  <Expandable title="Propriedades do usuário">
    <ResponseField name="id" type="string">
      ID único do usuário (ULID)
    </ResponseField>
    <ResponseField name="name" type="string">
      Nome do usuário
    </ResponseField>
    <ResponseField name="email" type="string">
      Email do usuário
    </ResponseField>
    <ResponseField name="token" type="string">
      Token de autenticação para usar nas próximas requisições
    </ResponseField>
    <ResponseField name="balance" type="integer">
      Saldo de créditos do usuário
    </ResponseField>
    <ResponseField name="subscription" type="object">
      Dados da assinatura ativa (se houver)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.realoficial.com.br/api/v1/login" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "usuario@exemplo.com",
    "password": "sua_senha"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.realoficial.com.br/api/v1/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    email: 'usuario@exemplo.com',
    password: 'sua_senha'
  })
});

const data = await response.json();
console.log(data.user.token); // Use este token nas próximas requisições
```

```python Python
import requests

response = requests.post(
    'https://api.realoficial.com.br/api/v1/login',
    json={
        'email': 'usuario@exemplo.com',
        'password': 'sua_senha'
    }
)

data = response.json()
token = data['user']['token']  # Use este token nas próximas requisições
```

```php PHP
$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'https://api.realoficial.com.br/api/v1/login',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => ['Content-Type: application/json'],
    CURLOPT_POSTFIELDS => json_encode([
        'email' => 'usuario@exemplo.com',
        'password' => 'sua_senha'
    ])
]);

$response = curl_exec($ch);
$data = json_decode($response, true);
$token = $data['user']['token']; // Use este token nas próximas requisições
```
</RequestExample>

## Próximos Passos

Após fazer login, use o `token` retornado no header `Authorization` de todas as requisições:

```bash
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```
