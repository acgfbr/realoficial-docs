Esta página torna explicitas limitações do contrato atual para que integrações não
dependam de probes, parâmetros ignorados ou rotas inexistentes.

## Aplicar Brand Kit automaticamente

O CRUD de Brand Kits está disponível, mas não existe uma operação dedicada para aplicar um
kit a todos os shorts de um projeto ou durante a renderização.

- `brand_kit_id` não é aceito por `/createShorts`;
- `brand_kit_id` não é aceito por `/shorts/{projectId}/{shortId}/render`;
- não existe `/projects/{projectId}/apply-brand-kit`.

Veja [Brand Kits](/api-reference/brand-kits) para o workaround por edição de timeline.

## Cancelar projeto em processamento

`DELETE /projects/{projectId}` só é aceito quando o projeto está em um destes status:

- `face_analysis_done`;
- `refunded_by_user`;
- `expired`;
- `refunded`;
- `try_again`.

Projetos em `pending`, `downloading`, `transcribing`, `transcribed` ou `shorts_created`
não podem ser cancelados. O endpoint retorna HTTP 400 pedindo para aguardar o
processamento.

```bash
curl -X DELETE \
  "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```

## Consultar um projeto singular

Não existe `GET /projects/{projectId}`. Use `GET /projects` e sua paginação. Quando a
integração também precisa dos cortes, `GET /shorts/{projectId}` inclui os dados do projeto
no campo `project`.

## Galeria de caption templates

Não existe `GET /caption-templates`. O campo `captionTemplate` de `/createShorts` recebe o
JSON completo do template, não apenas um identificador.

Os 33 modelos atualmente disponíveis, seus identificadores e estilos estão documentados no
[catálogo de Caption Templates](/api-reference/caption-templates). A
[galeria interativa](https://app.realoficial.com.br/docs/caption-templates) permite visualizar
cada animação e copiar o JSON completo.

Os endpoints `/user/caption-styles` armazenam estilos personalizados do próprio usuário;
eles não representam a galeria oficial de templates.

## Respostas e erros

A API v1 preserva envelopes históricos diferentes entre recursos. Consulte sempre a
página do endpoint e não dependa de um envelope global único. Da mesma forma, regras de
negócio antigas podem responder 400 enquanto validações estruturadas respondem 422.

## Recursos de IA

[Dublagem](/api-reference/dubbing), [tradução de legendas](/api-reference/translations),
[geração de imagem](/api-reference/images) e [thumbnails](/api-reference/thumbnails) são
assíncronos e não possuem webhook. Acompanhe cada pedido por polling no endpoint de
status indicado em cada guia.

- não existe endpoint para apagar uma dublagem ou uma tradução;
- não é possível refazer a tradução de um idioma já traduzido no mesmo short;
- `POST /renders/bulk` não aceita `dub_id` nem `subtitle_translation_id`;
- gerações de imagem avulsas não podem ser listadas depois: guarde os `ids` da resposta;
- a geração de imagem não aceita largura, altura, proporção nem mais de uma referência.
