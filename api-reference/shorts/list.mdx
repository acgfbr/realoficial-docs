---
title: 'Listar Shorts'
api: 'GET /shorts/{projectId}'
description: 'Liste todos os cortes (shorts) de um projeto'
---

## Endpoint

```
GET https://api.realoficial.com.br/api/v1/shorts/{projectId}
```

<Note>
Este endpoint requer autenticação via Bearer Token.
</Note>

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto (ULID)
</ParamField>

## Query Parameters

<ParamField query="page" type="integer">
  Número da página (padrão: 1)
</ParamField>

<ParamField query="limit" type="integer">
  Quantidade de itens por página (1-100, padrão: 20)
</ParamField>

<ParamField query="sort" type="string">
  Ordenação dos resultados:
  - `score` (padrão) - Por pontuação de relevância
  - `time` - Por tempo de início no vídeo
  - `duration` - Por duração do corte
</ParamField>

<ParamField query="render" type="string">
  Filtrar por status de renderização:
  - `all` (padrão) - Todos os cortes
  - `rendered` - Apenas renderizados
  - `not_rendered` - Apenas não renderizados
  - `liked` - Apenas marcados como favoritos
</ParamField>

## Resposta de Sucesso

<ResponseField name="message" type="string">
  Mensagem de confirmação
</ResponseField>

<ResponseField name="project" type="object">
  Dados resumidos do projeto
</ResponseField>

<ResponseField name="data" type="object">
  Objeto paginado com os shorts
  <Expandable title="Propriedades do short">
    <ResponseField name="id" type="string">
      ID único do short (ULID)
    </ResponseField>
    <ResponseField name="title" type="string">
      Título do corte
    </ResponseField>
    <ResponseField name="start_time" type="number">
      Tempo de início no vídeo original (segundos)
    </ResponseField>
    <ResponseField name="end_time" type="number">
      Tempo de fim no vídeo original (segundos)
    </ResponseField>
    <ResponseField name="score" type="number">
      Pontuação de relevância (0-10, normalmente com uma casa decimal)
    </ResponseField>
    <ResponseField name="status" type="string">
      Status do processamento
    </ResponseField>
    <ResponseField name="has_render" type="boolean">
      Se já foi renderizado
    </ResponseField>
    <ResponseField name="thumbnail_url" type="string">
      Imagem de capa **deste corte** (frame real do trecho).

      Não confunda com o `thumbnail_url` do nível `project`, que é a capa do vídeo
      original e é igual para todos os cortes.
    </ResponseField>
    <ResponseField name="preview_thumbnail_url" type="string">
      JPG de thumbnail do corte, servido pelo CDN público:
      `https://cdn.realoficial.com.br/shorts/{projectId}/{shortId}_thumbnail.jpg`

      Veja [Preview do Short](/api-reference/shorts/preview) para o vídeo MP4 de
      pré-visualização equivalente.
    </ResponseField>
    <ResponseField name="feedback" type="string">
      Feedback do usuário (`like`, `dislike`, ou array de motivos)
    </ResponseField>
    <ResponseField name="timeline" type="object">
      Dados da timeline para edição (assets, tracks, items)
    </ResponseField>
    <ResponseField name="renders" type="array">
      Lista de renderizações deste short
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Metadados agregados
  <Expandable title="Propriedades">
    <ResponseField name="average_score" type="number">
      Pontuação média dos cortes
    </ResponseField>
    <ResponseField name="average_duration" type="number">
      Duração média em segundos
    </ResponseField>
  </Expandable>
</ResponseField>

## Entendendo a Pontuação (Score)

A pontuação indica a relevância do corte identificado pela IA:

| Faixa | Classificação | Descrição |
|-------|---------------|-----------|
| 8.0-10.0 | Excelente | Momentos de alto engajamento potencial |
| 6.0-7.9 | Bom | Bons trechos para conteúdo |
| 4.0-5.9 | Médio | Pode funcionar com edição |
| 0.0-3.9 | Baixo | Menos recomendado |

<Info>
**Dica**: Comece renderizando os cortes com maior pontuação para maximizar o engajamento.
</Info>

## Obter Short Específico

Para obter detalhes de um short específico:

```
GET /shorts/{projectId}/{shortId}
```

<RequestExample>
```bash cURL
curl -X GET "https://api.realoficial.com.br/api/v1/shorts/PROJECT_ID/SHORT_ID" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>

Retorna o objeto completo do short incluindo a timeline para edição.
