title: 'Preview do Short'
description: 'Vídeo de preview (MP4) de cada corte, servido pelo CDN público'
---

## Visão geral

Cada corte gerado tem um **vídeo de preview em MP4** publicado no CDN. Ele é uma versão
comprimida e de baixa resolução do corte, usada para pré-visualização — não é o arquivo
final de render.

É o mesmo arquivo que o painel da Real Oficial usa para exibir os cards de cada corte na
tela de projeto.

## Padrão da URL

```
https://cdn.realoficial.com.br/shorts/{projectId}/{shortId}_preview.mp4
```

Onde `projectId` e `shortId` são os mesmos ULIDs retornados por
[Listar Shorts](/api-reference/shorts/list).

<Note>
O CDN é **público**: a URL não exige `Authorization`, token ou assinatura. Não use estas
URLs para conteúdo que precise ser privado.
</Note>

## Verificando a disponibilidade

```bash
curl -I https://cdn.realoficial.com.br/shorts/PROJECT_ID/SHORT_ID_preview.mp4
```

```
HTTP/2 200
content-type: video/mp4
content-length: 6756411
accept-ranges: bytes
etag: "f983f592a6a7b16ca646a2c35adcabdf"
server: cloudflare
cf-cache-status: DYNAMIC
```

Como o CDN responde `accept-ranges: bytes`, o player do navegador consegue baixar apenas
o trecho inicial do arquivo em vez do MP4 inteiro.

## Uso no cliente

```html
<video
  src="https://cdn.realoficial.com.br/shorts/{projectId}/{shortId}_preview.mp4"
  muted
  playsinline
  preload="metadata"
/>
```

<Tip>
`preload="metadata"` faz o navegador buscar apenas os metadados e o primeiro frame, sem
baixar o vídeo completo. É o que permite usar o preview como thumbnail sem custo de banda
relevante.
</Tip>

## Thumbnail por corte

Cada short também expõe um **JPG de thumbnail** próprio, no campo `preview_thumbnail_url`
retornado pelos endpoints de short:

```
https://cdn.realoficial.com.br/shorts/{projectId}/{shortId}_thumbnail.jpg
```

Se você só precisa de uma imagem estática por corte, prefira esse campo — é mais leve que
carregar metadados de um MP4.

<Warning>
Não confunda com `thumbnail_url` no nível do `project`: aquele é a capa do **vídeo
original**, igual para todos os cortes do mesmo projeto. O preview é o
`preview_thumbnail_url` são por corte, mostrando o frame real do trecho.
</Warning>

## Disponibilidade

O preview é gerado durante o processamento do corte, junto com o próprio short. Ele fica
disponível a partir do momento em que o corte aparece na listagem.

<Warning>
Assim como os demais arquivos de um projeto, os previews seguem a política de **retenção
de 30 dias**. Depois disso a URL passa a responder `404`. Trate o erro no cliente em vez
de assumir que o arquivo existe para sempre.
</Warning>
