---
title: 'Reprompt (Regerar Cortes)'
api: 'POST /projects/{projectId}/reprompt'
description: 'Gere novos cortes de um vídeo já processado, guiando a IA com um prompt'
---

## Endpoint

```
POST https://api.realoficial.com.br/api/v1/projects/{projectId}/reprompt
```

<Note>
Este endpoint requer autenticação via Bearer Token e **assinatura ativa**.
</Note>

O reprompt reaproveita a URL e as configurações de um projeto já existente para gerar
cortes novos, guiados por uma instrução em texto. É útil quando os cortes automáticos não
capturaram o ângulo que você queria.

<Warning>
O reprompt **cria um projeto novo** — ele não altera nem adiciona cortes ao projeto
original. O projeto retornado tem `source_project_id` apontando para o original, e começa
do zero no fluxo de processamento.
</Warning>

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto de origem (ULID)
</ParamField>

## Body Parameters

<ParamField body="prompt" type="string" required>
  Instrução para a IA sobre quais momentos priorizar. Máximo 2000 caracteres.

  Exemplo: `"foque em momentos sobre saúde pública e SUS"`
</ParamField>

<ParamField body="startTime" type="number" required>
  Início do intervalo a analisar, em segundos.
</ParamField>

<ParamField body="endTime" type="number" required>
  Fim do intervalo a analisar, em segundos.
</ParamField>

<ParamField body="clipDuration" type="string">
  Duração alvo dos cortes. Herda do projeto original se omitido.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  `vertical` ou `horizontal`. Herda do projeto original se omitido.

  O formato `horizontal` exige plano Criador ou Viral.
</ParamField>

<ParamField body="layout" type="string">
  Layout do vídeo: `auto`, `single`, `center`, `split`, `react` ou `pf`.
  Herda do projeto original se omitido.
</ParamField>

<ParamField body="captionTemplate" type="string">
  Template de legenda. Herda do projeto original se omitido.
</ParamField>

<ParamField body="captionFont" type="string">
  Fonte das legendas. Herda do projeto original se omitido.
</ParamField>

<ParamField body="ignoreCaptions" type="boolean">
  Gera os cortes sem legendas.
</ParamField>

## Validações

| Regra | Limite |
|-------|--------|
| Intervalo mínimo (`endTime - startTime`) | 5 minutos (300 segundos) |
| Tamanho do `prompt` | 2000 caracteres |
| Assinatura | Ativa, com cota de reprompt maior que zero |

## Custo e cota diária

Cada plano tem uma cota de reprompts **gratuitos por dia**. Enquanto houver cota, o
reprompt não consome créditos.

| Plano | Reprompts grátis/dia |
|-------|----------------------|
| Viral | 3 |
| Criador | 2 |
| Lite | 1 |
| Sem assinatura ativa | 0 (endpoint retorna `403`) |

Esgotada a cota do dia, o reprompt passa a ser cobrado em créditos:

```
custo = ceil(ceil((endTime - startTime) / 60) * 0.5)
```

Ou seja, meio crédito por minuto do intervalo, arredondado para cima. Um intervalo de 15
minutos custa 8 créditos.

Acompanhe o consumo pelos campos de reprompt retornados em
[Dados do Usuário](/api-reference/auth/user).

## Resposta de Sucesso

<ResponseField name="project" type="object">
  O **novo** projeto criado, no mesmo formato de
  [Listar Projetos](/api-reference/projects/list).
</ResponseField>

<ResponseField name="is_free" type="boolean">
  `true` se este reprompt usou a cota diária gratuita, `false` se foi cobrado em créditos.
</ResponseField>

<ResponseField name="credits_charged" type="integer">
  Créditos debitados. `0` quando `is_free` é `true`.
</ResponseField>

<Note>
A resposta usa o envelope `project`, e não `data` como o `createShorts`. Os campos de cota
(`reprompts_today`, `reprompts_free_remaining`) **não** são retornados aqui — consulte
`/user` para o estado atualizado.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID/reprompt" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "prompt": "foque em momentos sobre saúde pública e SUS",
    "startTime": 900,
    "endTime": 1800
  }'
```

```javascript JavaScript
const response = await fetch(
  `https://api.realoficial.com.br/api/v1/projects/${projectId}/reprompt`,
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer seu_token_aqui',
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    },
    body: JSON.stringify({
      prompt: 'foque em momentos sobre saúde pública e SUS',
      startTime: 900,
      endTime: 1800
    })
  }
);

const { project, is_free, credits_charged } = await response.json();
```

```python Python
import requests

response = requests.post(
    f'https://api.realoficial.com.br/api/v1/projects/{project_id}/reprompt',
    headers={
        'Authorization': 'Bearer seu_token_aqui',
        'Content-Type': 'application/json',
        'Accept': 'application/json'
    },
    json={
        'prompt': 'foque em momentos sobre saúde pública e SUS',
        'startTime': 900,
        'endTime': 1800
    }
)

data = response.json()
```
</RequestExample>

## Acompanhando o resultado

O projeto retornado começa com `status: null` e segue o fluxo normal de processamento.
Para saber quando os cortes ficam prontos, use
[Listar Shorts](/api-reference/shorts/list) no ID do **novo** projeto, ou configure um
`webhook_url` em [Atualizar Perfil](/api-reference/auth/profile) para receber o evento
`project.ready`.
