## Endpoint

```text
POST https://api.realoficial.com.br/api/v1/projects
```

Este endpoint cria somente o contêiner do projeto. Ele não baixa vídeo, não executa IA,
não cria shorts e não consome créditos de processamento.

<Note>
O projeto vazio exige autenticação e uma assinatura ativa de qualquer plano pago,
incluindo o Lite. Para conhecer a disponibilidade geral da API, consulte
[Planos e acesso à API](/plans).
</Note>

## Body

<ParamField body="title" type="string" required>
  Nome do projeto. O valor persistido possui no máximo 255 caracteres.
</ParamField>

## Workspace

Sem `X-Workspace-Id`, o projeto é criado no espaço pessoal. Para criar dentro de um
workspace, envie o ID no header e autentique um membro com permissão para gerenciar
projetos:

```bash
X-Workspace-Id: 01KZWORKSPACE000000000001
```

O requisito de assinatura é validado no dono do workspace.

## Exemplo

<RequestExample>
```bash cURL
curl -X POST "https://api.realoficial.com.br/api/v1/projects" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "title": "Conteúdos da campanha de setembro"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.realoficial.com.br/api/v1/projects', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer seu_token_aqui',
    'Content-Type': 'application/json',
    Accept: 'application/json'
  },
  body: JSON.stringify({
    title: 'Conteúdos da campanha de setembro'
  })
});

const { data: project } = await response.json();
console.log(project.id);
```

```python Python
import requests

response = requests.post(
    'https://api.realoficial.com.br/api/v1/projects',
    headers={
        'Authorization': 'Bearer seu_token_aqui',
        'Accept': 'application/json',
    },
    json={'title': 'Conteúdos da campanha de setembro'},
)

project = response.json()['data']
print(project['id'])
```
</RequestExample>

## Diferença para a geração automática

| Endpoint | Resultado | Consome créditos de processamento? |
|---|---|---|
| `POST /projects` | Projeto vazio, sem vídeo ou shorts | Não |
| `POST /createShorts` | Projeto criado a partir de um vídeo, com geração automática | Sim |

Para processar uma URL e gerar cortes automaticamente, use
[Criar Projeto com IA](/api-reference/projects/create).
