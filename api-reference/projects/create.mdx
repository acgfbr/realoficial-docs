## Endpoint

```
POST https://api.realoficial.com.br/api/v1/createShorts
```

<Note>
Este endpoint requer autenticacao e consome creditos do usuario.
</Note>

## Body Parameters

<ParamField body="url" type="string" required>
  URL do video (YouTube, Google Drive ou link direto .mp4)
</ParamField>

<ParamField body="clipDuration" type="string" required>
  Duracao alvo dos cortes: `30`, `60`, `90`, `120` ou `auto`
</ParamField>

<ParamField body="startTime" type="number" required>
  Tempo inicial do trecho a processar (em segundos)
</ParamField>

<ParamField body="endTime" type="number" required>
  Tempo final do trecho a processar (em segundos)
</ParamField>

<ParamField body="aspect_ratio" type="string" required>
  Formato do video: `vertical` (9:16) ou `horizontal` (16:9)
</ParamField>

<ParamField body="layout" type="string">
  Layout do video: `auto`, `single`, `split`, `react`, `gaming`

  - `auto`: Layout combinado entre single / split e center
  - `single`: Video unico com face tracking
  - `split`: Tela dividida (face + conteudo)
  - `center`: Vídeo centralizado na tela
  - `react`: Estilo reacao
  - `gaming`: Para gameplays
</ParamField>

<ParamField body="video_type" type="string" required>
  Tipo de processamento. Valores aceitos: `shorts` ou `reframe`.

  <Warning>
  Este campo e **obrigatorio**. Omiti-lo retorna `422`:

  ```json
  {
    "message": "The video type field is required.",
    "errors": {
      "video_type": ["The video type field is required."]
    }
  }
  ```
  </Warning>

  O modo escolhido muda as regras de duracao do intervalo — veja
  [Validacoes](#validacoes).
</ParamField>

<ParamField body="title" type="string">
  Titulo personalizado do projeto (usa titulo do video se nao informado)
</ParamField>

<ParamField body="captionFont" type="string">
  Fonte padrao para legendas
</ParamField>

<ParamField body="captionTemplate" type="json">
  Objeto completo do estilo de legendas, com `id`, `style` e `config`. Consulte o
  [catálogo de Caption Templates](/api-reference/caption-templates) ou copie o JSON
  pela [galeria interativa](https://app.realoficial.com.br/docs/caption-templates).
</ParamField>

<ParamField body="ignoreCaptions" type="boolean" default="false">
  Se `true`, gera os cortes **sem legendas**.
</ParamField>

<ParamField body="prompt" type="string">
  Prompt customizado para guiar a geracao dos cortes. Maximo de **1000 caracteres**.
</ParamField>

<ParamField body="emojisEnabled" type="boolean" default="false">
  Se `true`, habilita emojis nas legendas.
</ParamField>

<ParamField body="show_in_content_hub" type="boolean" default="true">
  Se `true`, compartilha os cortes no hub de conteudo.
</ParamField>

<ParamField body="autoCta" type="boolean" default="false">
  Se `true`, adiciona uma chamada para acao (CTA) nos primeiros 3 segundos do corte.
</ParamField>

## Custo em Creditos

<Warning>
**1 credito = 1 minuto de video processado**

O custo e calculado automaticamente com base no intervalo `endTime - startTime`.
</Warning>

## Validacoes

As regras de intervalo dependem do `video_type` (e, no modo `reframe`, tambem do
`layout`). O intervalo e sempre `endTime - startTime`.

### Modo `shorts`

| Regra | Limite |
|-------|--------|
| Intervalo minimo | **5 minutos** (300 segundos) |
| Intervalo maximo | 20 horas (72000 segundos) |
| Duracao maxima do video | 10 horas |
| Videos > 5h | Intervalo minimo de 1 hora |
| Videos > 3h | Requer assinatura ativa |

Um intervalo de exatamente 300 segundos e aceito; 299 segundos ou menos retorna `400`:

```json
{ "error": "Você precisa selecionar um intervalo de pelo menos 5 minutos." }
```

### Modo `reframe`

| Regra | Limite |
|-------|--------|
| Intervalo minimo | 15 segundos |
| Intervalo maximo com `layout: center` | 60 minutos (3600 segundos) |
| Intervalo maximo nos demais layouts | 5 minutos (300 segundos) |

<Note>
Repare que o intervalo de 5 minutos e o **piso** no modo `shorts` e o **teto** no modo
`reframe` (fora do layout `center`).
</Note>

<Warning>
Durante campanhas sazonais podem valer limites adicionais mais restritivos para o modo
`shorts`. Nesses casos a resposta `400` inclui o campo `event_limit: true`.
</Warning>

## Status do Projeto

Apos criar o projeto, ele passara pelos seguintes status:

| Status | Descricao |
|--------|-----------|
| `pending` | Aguardando processamento |
| `downloading` | Baixando o video |
| `transcribing` | Transcrevendo audio |
| `transcribed` | Transcricao concluida |
| `shorts_created` | Cortes identificados |
| `face_analysis_done` | Pronto para uso |
| `refunded` | Reembolsado |

<Info>
**Polling recomendado**: Consulte `GET /shorts/{projectId}` a cada 10-30 segundos para verificar quando os cortes estao prontos.
</Info>

## Visualizar Cortes

Apos o projeto ser processado, voce pode visualizar os cortes gerados atraves de uma pagina de preview:

```
https://app.realoficial.com.br/share/{projectId}?token={seu_token}
```

## URLs Suportadas

<AccordionGroup>
  <Accordion title="YouTube">
    - `https://www.youtube.com/watch?v=VIDEO_ID`
    - `https://youtu.be/VIDEO_ID`
    - Videos com duracao suficiente para o intervalo minimo (veja [Validacoes](#validacoes))
    - YouTube Shorts **nao** sao suportados
  </Accordion>
  <Accordion title="Google Drive">
    - Links de compartilhamento publico
    - Maximo 10GB por arquivo
  </Accordion>
  <Accordion title="Link Direto">
    - URLs terminando em `.mp4`
    - Maximo 10GB por arquivo
  </Accordion>
</AccordionGroup>
