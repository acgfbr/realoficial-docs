---

## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/ai-usage/image/queue
```

Útil para acompanhar várias gerações de uma vez e mostrar ao usuário quanto a fila está
cheia. Não traz URLs de imagem, posição na fila nem previsão de término: para o
resultado, use [Consultar Imagem](/api-reference/images/show).

<Note>
Rate limit: 60 requisições por minuto. Respeite `poll_after_ms` entre consultas.
</Note>

## Query Parameters

<ParamField query="ids[]" type="array">
  Até 50 IDs de geração, repetindo o parâmetro (`ids[]=A&ids[]=B`). IDs inexistentes ou
  de outra conta são ignorados.
</ParamField>

## Resposta

<ResponseField name="global" type="object">
  Volume da fila de toda a plataforma: `queued`, `processing`, `total` e `sampled_at`.
</ResponseField>
<ResponseField name="own" type="object">
  Suas gerações em andamento: `queued`, `processing`, `total`, `economy` (pedidos do modo
  econômico esperando, fora das outras contagens) e `jobs` (com `id`, `status`,
  `economy`, `model`, `created_at`, `updated_at`).
</ResponseField>
<ResponseField name="poll_after_ms" type="integer">Intervalo recomendado até a próxima consulta.</ResponseField>

<RequestExample>
```bash cURL
curl -G "https://api.realoficial.com.br/api/v1/ai-usage/image/queue" \
  --data-urlencode "ids[]=01k6img0000000000000000001" \
  --data-urlencode "ids[]=01k6img0000000000000000002" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
