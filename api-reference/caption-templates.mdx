---
title: 'Caption Templates'
description: 'Catálogo de estilos de legenda aceitos pelo createShorts'
---

Caption Templates controlam somente a aparência e a animação das legendas. Eles são
diferentes dos [Templates de Composição](/api-reference/templates), que podem incluir
vídeo, imagens, textos, formas, Brand Kit e outras camadas.

O campo `captionTemplate` de `POST /createShorts` recebe o objeto completo do template.
Enviar apenas o `id` não aplica os valores padrão de `style` e `config`.

<Note>
Não existe atualmente um endpoint `GET /caption-templates`. Esta página documenta o
catálogo oficial usado pelo frontend. Para visualizar as animações e copiar o JSON exato,
use a [galeria interativa](https://app.realoficial.com.br/docs/caption-templates).
</Note>

## Formato do campo

```json
{
  "captionTemplate": {
    "id": "simple-white",
    "style": "colored-words",
    "config": {
      "fontFamily": "Inter",
      "fontSize": 75,
      "fontWeight": "bold",
      "textTransform": "none",
      "primaryColor": "#ffffff",
      "secondaryColor": "#ffffff",
      "strokeColor": "#000000",
      "strokeWidth": 6,
      "maxWidth": 900
    }
  }
}
```

| Campo | Tipo | Descrição |
|---|---|---|
| `id` | string | Identificador do modelo no catálogo |
| `style` | string | Motor de animação usado pelo renderer |
| `config` | object | Fonte, cores, contorno, dimensões e parâmetros do estilo |

Os campos comuns de `config` são `fontFamily`, `fontSize`, `fontWeight`,
`textTransform`, `primaryColor`, `secondaryColor`, `backgroundColor`, `strokeColor`,
`strokeWidth`, `maxWidth`, `padding`, `borderRadius`, `animationDuration`,
`animationDelay`, `scaleAmount`, `highlightColor`, `enableEmojis`, `keywordsEnabled`,
`keywordColor` e `entryAnimation`. Alguns estilos usam apenas um subconjunto deles.

## Template surpresa

O identificador especial `surprise` seleciona um estilo aleatório para cada vídeo:

```json
{
  "captionTemplate": {
    "id": "surprise",
    "style": "random",
    "config": {
      "fontFamily": "Montserrat"
    }
  }
}
```

Para desativar as legendas por completo, envie `ignoreCaptions: true` no
`POST /createShorts`; nesse caso `captionTemplate` é ignorado.
