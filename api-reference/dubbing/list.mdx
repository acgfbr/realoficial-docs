title: 'Listar Dublagens'
api: 'GET /projects/{projectId}/shorts/{shortId}/dubs'
description: 'Lista as dublagens de um short, das mais recentes para as mais antigas'
---

## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/projects/{projectId}/shorts/{shortId}/dubs
```

Retorna até 30 dublagens do short, das mais recentes para as mais antigas, no mesmo
formato de [Consultar Dublagem](/api-reference/dubbing/show).

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto (ULID).
</ParamField>

<ParamField path="shortId" type="string" required>
  ID do short (ULID).
</ParamField>

## Resposta

<ResponseField name="project_id" type="string">ID do projeto.</ResponseField>
<ResponseField name="short_id" type="string">ID do short.</ResponseField>
<ResponseField name="source_language" type="string | null">
  Idioma original do short, no formato dos códigos de dublagem. `null` quando ainda não
  foi detectado.
</ResponseField>
<ResponseField name="dubs" type="array">Lista de objetos `dub`.</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID/shorts/SHORT_ID/dubs" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
