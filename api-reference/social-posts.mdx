## Endpoints

| Método | Endpoint | Descrição |
|---|---|---|
| `GET` | `/social/posts` | Lista publicações |
| `POST` | `/social/posts` | Publica ou agenda um short |
| `GET` | `/social/posts/{id}` | Retorna uma publicação |
| `PATCH` | `/social/posts/{id}` | Atualiza a publicação e seus destinos |
| `DELETE` | `/social/posts/{id}` | Remove o registro local |
| `POST` | `/social/posts/{id}/retry` | Tenta novamente todos os destinos com falha |
| `POST` | `/social/posts/{id}/retry/{socialPostId}` | Tenta novamente um destino |

## Listar publicações

<ParamField query="limit" type="integer">
  Itens por página, entre 1 e 1000. Padrão: 20.
</ParamField>

<ParamField query="status" type="string | array">
  Um status ou uma lista separada por vírgulas: `draft`, `scheduled`, `processing`,
  `published` ou `failed`.
</ParamField>

```bash
curl "https://api.realoficial.com.br/api/v1/social/posts?status=scheduled,failed&limit=50" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```

## Criar publicação

```text
POST /social/posts
```

<ParamField body="short_id" type="string" required>
  ID de um short do workspace com timeline renderizável.
</ParamField>

<ParamField body="social_accounts" type="array" required>
  Lista de destinos. Cada item exige `id` e pode sobrescrever `title` e `description`.
</ParamField>

<ParamField body="title" type="string" required>
  Título padrão, com até 255 caracteres.
</ParamField>

<ParamField body="description" type="string">
  Descrição padrão, com até 5000 caracteres.
</ParamField>

<ParamField body="scheduled_at" type="string">
  Horário futuro no formato `YYYY-MM-DD HH:mm:ss`, interpretado no fuso
  `America/Sao_Paulo`. O agendamento pode ficar no máximo 60 dias no futuro.
</ParamField>

<ParamField body="tiktok_guidelines_filter_enabled" type="boolean">
  Ativa o filtro de diretrizes do TikTok. Padrão: `true`.
</ParamField>

<ParamField body="tags" type="array">
  Até 10 tags, com no máximo 50 caracteres cada.
</ParamField>

<ParamField body="auto_reply_config" type="object">
  Automação opcional. `name` e `dm_message` são obrigatórios quando o objeto é enviado;
  também aceita `comment_reply`, `keywords` e `match_mode` (`exact` ou `contains`).
</ParamField>

Se `scheduled_at` for omitido, a publicação é iniciada imediatamente. Caso o short ainda
não tenha render final, o fluxo cria ou aguarda a renderização antes de publicar.

<RequestExample>
```bash cURL
curl -X POST "https://api.realoficial.com.br/api/v1/social/posts" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "short_id": "01k4ef56yqtsyrzjb0gveqy7cd",
    "title": "Novo corte",
    "description": "Confira este trecho",
    "scheduled_at": "2026-08-20 18:30:00",
    "social_accounts": [
      {
        "id": "01ksocialaccount000000000001",
        "title": "Título específico para esta conta"
      }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json 201 - Agendado
{
  "message": "Publicação agendada com sucesso.",
  "post": {
    "id": "01kpost00000000000000000001",
    "short_id": "01k4ef56yqtsyrzjb0gveqy7cd",
    "status": "scheduled",
    "scheduled_at": "2026-08-20T21:30:00.000000Z",
    "social_posts": []
  }
}
```
</ResponseExample>

## Atualizar

`PATCH /social/posts/{id}` aceita `title`, `description`, `scheduled_at`,
`tiktok_guidelines_filter_enabled`, `auto_reply_config` e exige `social_accounts` com ao
menos um destino. Títulos e descrições podem ser personalizados por conta.

Uma atualização pode responder `207 Multi-Status` quando o registro local foi salvo, mas
alguma plataforma não permite ou recusou a alteração do post já publicado.

## Excluir

`DELETE /social/posts/{id}` remove o post e seus destinos do banco da Real Oficial. A
operação atual **não apaga vídeos que já foram publicados nas plataformas externas**.

## Retry

Use os endpoints de retry somente para destinos com status `failed`. O retorno informa os
destinos reenfileirados e os erros que não puderam ser recuperados.
