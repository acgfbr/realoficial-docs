---
title: 'Detalhar Template'
api: 'GET /templates/{id}'
description: 'Retorna um template próprio ou público aprovado'
---

<Note>
Este endpoint requer autenticação via Bearer token e opera no workspace ativo.
</Note>

Retorna um template próprio ou público aprovado.

Consulte o [guia completo de Templates de Composição](/api-reference/templates) para parâmetros,
regras de validação, exemplos e efeitos colaterais desta operação.
