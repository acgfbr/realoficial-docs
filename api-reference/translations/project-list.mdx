---
title: 'Listar Traduções do Projeto'
api: 'GET /projects/{projectId}/translations'
description: 'Lista as traduções de legenda de todos os shorts de um projeto'
---

## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/projects/{projectId}/translations
```

Retorna, numa única chamada, as traduções de todos os shorts do projeto e os idiomas
configurados para tradução automática. Agrupe por `short_id` para montar a visão de cada
corte.

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto (ULID).
</ParamField>

## Resposta

<ResponseField name="project_id" type="string">ID do projeto.</ResponseField>
<ResponseField name="requested_languages" type="array">Idiomas configurados para tradução automática dos shorts do projeto.</ResponseField>
<ResponseField name="translations" type="array">
  <Expandable title="Propriedades">
    <ResponseField name="id" type="string">ID da tradução (`subtitle_translation_id`).</ResponseField>
    <ResponseField name="short_id" type="string">Short traduzido.</ResponseField>
    <ResponseField name="scope" type="string">`short` ou `project`, conforme a origem do pedido.</ResponseField>
    <ResponseField name="language" type="string">Idioma da tradução.</ResponseField>
    <ResponseField name="status" type="string">`dispatching`, `processing`, `completed` ou `failed`.</ResponseField>
    <ResponseField name="preview_ready" type="boolean">Se a tradução já pode ser usada.</ResponseField>
    <ResponseField name="credits_charged" type="integer">Sempre `0`.</ResponseField>
    <ResponseField name="completed_at" type="string | null">Conclusão.</ResponseField>
    <ResponseField name="error" type="string | null">Mensagem de falha, só em `failed`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID/translations" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
