description: 'Lista as sessões de thumbnail de um short com as opções geradas'
---

## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/projects/{projectId}/shorts/{shortId}/ai-thumbnail-sessions
```

Retorna as 20 sessões mais recentes do short e qualquer sessão que ainda tenha geração
em andamento. Cada sessão traz suas opções em `generations`. Use também para recuperar os
IDs de um pedido de geração cuja resposta se perdeu.

Opções ocultadas com
[Ocultar Opção](/api-reference/thumbnails/generations-hide) não aparecem.

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto (ULID).
</ParamField>

<ParamField path="shortId" type="string" required>
  ID do short (ULID).
</ParamField>

<RequestExample>
```bash cURL
curl "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID/shorts/SHORT_ID/ai-thumbnail-sessions" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
