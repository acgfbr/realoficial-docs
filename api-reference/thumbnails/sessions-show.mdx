## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/projects/{projectId}/shorts/{shortId}/ai-thumbnail-sessions/{sessionId}
```

Retorna a sessão no mesmo formato de
[Criar Sessão de Thumbnail](/api-reference/thumbnails/sessions-create), com as opções
geradas em `generations`.

## Path Parameters

<ParamField path="projectId" type="string" required>
  ID do projeto (ULID).
</ParamField>

<ParamField path="shortId" type="string" required>
  ID do short (ULID).
</ParamField>

<ParamField path="sessionId" type="string" required>
  ID da sessão (ULID).
</ParamField>

<RequestExample>
```bash cURL
curl "https://api.realoficial.com.br/api/v1/projects/PROJECT_ID/shorts/SHORT_ID/ai-thumbnail-sessions/SESSION_ID" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
