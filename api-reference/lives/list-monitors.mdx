---

## Endpoint

```
GET https://api.realoficial.com.br/api/v1/lives/monitors
```

<Note>
Este endpoint requer autenticação via Bearer Token.
</Note>

Retorna os monitors do usuário autenticado em um paginator Laravel configurado atualmente
com `per_page: 1000`.

## Query Parameters

<ParamField query="visibility" type="string">
  Filtrar por visibilidade: `public` ou `private`
</ParamField>

<ParamField query="page" type="integer">
  Número da página (padrão: 1)
</ParamField>

<Warning>
O endpoint não aceita `per_page` no contrato atual. O backend usa o valor fixo `1000`.
</Warning>

<RequestExample>
```bash cURL
curl -X GET "https://api.realoficial.com.br/api/v1/lives/monitors?visibility=public" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
