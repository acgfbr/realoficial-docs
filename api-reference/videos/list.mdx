---

## Endpoint

```text
GET https://api.realoficial.com.br/api/v1/ai-usage/video
```

Traz os vídeos do workspace atual (inclusive os pedidos por outros membros), no mesmo
formato de [Consultar Vídeo](/api-reference/videos/show), e as vagas da conta.

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Página.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Itens por página, de 1 a 50.
</ParamField>

## Resposta

<ResponseField name="data" type="array">Vídeos, no formato de [Consultar Vídeo](/api-reference/videos/show) (sem `queue` em cada item).</ResponseField>
<ResponseField name="meta" type="object">`current_page`, `last_page`, `per_page` e `total`.</ResponseField>
<ResponseField name="queue" type="object">Vagas da conta agora: `slots`, `queue_limit`, `active` e `queued`.</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.realoficial.com.br/api/v1/ai-usage/video?page=1&limit=20" \
  -H "Authorization: Bearer seu_token_aqui" \
  -H "Accept: application/json"
```
</RequestExample>
