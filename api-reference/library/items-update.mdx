---
title: 'Atualizar Item'
api: 'PUT /library/items/{id}'
description: 'Atualiza ou move um item da Biblioteca'
---

<Note>
Este endpoint requer autenticação via Bearer token e opera no workspace ativo.
</Note>

Atualiza ou move um item da Biblioteca.

Consulte o [guia completo de Biblioteca](/api-reference/library) para parâmetros,
regras de validação, exemplos e efeitos colaterais desta operação.
